# Future Interns — Task 3: Marketing Campaign Analysis

## Project Overview
This project analyzes a bank marketing campaign dataset to understand customer responses and identify patterns associated with successful term deposit subscriptions. It was completed as part of the Future Interns Data Science Internship — Task 3.

## Objectives
- Calculate the overall campaign conversion rate.
- Compare conversion rates across contact methods and months.
- Analyze customer responses by job category.
- Examine the relationship between previous campaign outcomes and current responses.
- Generate visualizations and practical business recommendations.

## Dataset
The project uses the **Bank Marketing Dataset** from the UCI Machine Learning Repository.

**Dataset source:** https://archive.ics.uci.edu/dataset/222/bank+marketing

The analysis uses `bank-full.csv`, containing 45,211 customer records and information about customer demographics, contact details, campaign activity, and subscription responses.
